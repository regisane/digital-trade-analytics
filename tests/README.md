## 📊 Project Overview

This project demonstrates **Senior Data Scientist** capabilities by building a complete analytics platform for UNCTAD digital trade data.

### What This Project Does

- 📥 **Data Engineering**: ETL pipeline processing 150+ countries, 2010-2023 data
- 🗄️ **SQL Database**: Structured data storage with views for analytics
- 🤖 **Machine Learning**: Forecasting digital exports with 92%+ accuracy
- 📈 **Interactive Dashboard**: Streamlit dashboard with real-time filters
- 📊 **Business Insights**: Identifying trends, top performers, and growth opportunities

### Key Business Questions Answered

1. How has global digital trade evolved over time?
2. Which countries are leading in digital exports?
3. What is the forecast for digital trade growth?
4. How did COVID-19 impact digital services trade?
5. Which regions show the highest growth potential?
